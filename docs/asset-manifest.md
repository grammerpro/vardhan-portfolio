## Fonts and notices

The active layout uses Archivo and Geist Mono through `next/font/google`. Next emits self-hosted WOFF2 files; visitors do not request font files from Google. A fresh build can require network access to obtain the font source. Both families use SIL Open Font License 1.1, verified against the primary notices: [Archivo](https://github.com/google/fonts/blob/main/ofl/archivo/OFL.txt) and [Geist Mono](https://github.com/google/fonts/blob/main/ofl/geistmono/OFL.txt).

Local notices are `public/licenses/Archivo-OFL.txt` (4,388 bytes) and `public/licenses/Geist-Mono-OFL.txt` (4,387 bytes). They retain the respective copyright notices. No font was renamed or modified. Latin variable-font assets in the inspected build are:

| Build asset under `.next/static/media/` | Family | Bytes |
| --- | --- | ---: |
| `1a4aa50920b5315c-s.p.woff2` | Archivo Latin | 34,940 |
| `7d4881bb7e1bf84d-s.p.woff2` | Geist Mono Latin | 23,108 |

Other emitted language subsets are selected by CSS unicode ranges, not all preloaded. Build hashes may change after a font/dependency update. The old build also contained Geist Sans; the current layout does not request that family. Use the final build/network measurements in `docs/verification.md` for actual transferred bytes rather than summing a stale build directory.
