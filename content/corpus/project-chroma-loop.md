Chroma Loop is an independent browser arcade game written in TypeScript with Canvas 2D. Players rotate a colored ring to catch matching falling orbs. The public code includes keyboard and pointer input, seeded daily sequences, scoring, synthesized audio, local storage, and unit tests. It is not the Three.js shader-ribbon project described in the older portfolio. Source: https://github.com/grammerpro/Chroma-Loop at 90283a900cb7006c86d4957cfeea32f94bc1ff0b.
