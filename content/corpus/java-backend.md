Vardhan writes backend services in both Java and Node. On the Java side that is Spring Boot and Hibernate; on the Node side, Express and REST APIs. He has built and tested Node REST services and integrated them through a publish-subscribe layer on an enterprise platform. He works with GraphQL as well as REST. Databases he has used in production include PostgreSQL, MySQL, MongoDB, SQL Server, Oracle and Snowflake.
