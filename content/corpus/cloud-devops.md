Vardhan deploys to AWS using EC2, Lambda and S3, and containerises with Docker. His pipeline work has been mostly GitLab CI/CD, with exposure to Jenkins, GitHub and BitBucket. He integrates secret scanning with GGShield into the pipeline rather than treating security as a later review step. He has used Prometheus and Grafana for monitoring, and maintains a Linux workflow on Ubuntu through WSL.
