Vardhan’s independent Java retrieval project combines Spring Boot and Spring AI with a React and TypeScript interface. The inspected source configures OpenAI embeddings and chat models, with PostgreSQL and pgvector for similarity search. It ingests MedQuAD text and metadata, retrieves documents, builds a context prompt, and returns an answer with source labels. It is a research prototype; local-only inference, medical accuracy, production readiness, and benchmark improvements are not established.
