ANON Dapp is an independent React file-vault prototype using browser AES-GCM through Web Crypto. It supports local IndexedDB records and an optional Pinata upload path, then uses credentials carried in a URL fragment for client-side decryption. The local record stores an exported key alongside ciphertext; the local ledger and shard display are simulations. The inspected source does not establish a zero-knowledge proof framework, Solidity contracts, Ethereum integration, or production security.
