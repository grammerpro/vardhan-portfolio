Blockchain File Storage is an independent Python and Flask experiment. The web interface saves files locally, posts metadata to a local peer, and exposes a custom proof-of-work chain with SHA-256 hashing. Full peer consensus, file replication, confidentiality, and production storage guarantees were not established. The inspected source is not the Ethereum, Solidity, React, or IPFS stack listed by the older portfolio.
