React and TypeScript are Vardhan's primary front-end stack across five years. He builds interfaces from Figma files and holds them to the design rather than approximating it. He has integrated TypeScript controllers into an enterprise platform for dynamic UI and backend interaction, and built pages with dynamic data binding, reusable components and shimmer loading states. He writes Jest unit tests and works with QA rather than throwing builds over a wall. He also uses HTML5, CSS3, Bootstrap, Alpine.js and jQuery where a codebase already depends on them.
